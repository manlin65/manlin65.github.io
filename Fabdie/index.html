STL-Werkzeug · läuft lokal im Browser

Aus einem 3D-Modell
wird eine Negativform.

STL laden, einen Formblock erzeugen und das Modell als Hohlraum herausrechnen. Die Berechnung läuft auf diesem PC. Es wird nichts hochgeladen.

How-to: So ist die Seite entstanden

1 · STL auswählen

Noch keine Datei ausgewählt
Kleiner = glattere Form, längere Berechnung und größere Datei. Diese Demo erzeugt eine abgestufte Näherung.
Der Block wird an den Seiten und unter dem Modell erweitert.
Das Modell ragt oben aus dem Block heraus. Dadurch bleibt die Negativform geöffnet.
Lade die Beispiel-Kugel oder wähle eine eigene STL-Datei.
Negativ-STL herunterladen
Hinweis: Das Ergebnis wird als Voxel-Näherung erzeugt und hat sichtbare Rasterstufen. Für einen echten 3D-Druck bitte in einem Slicer prüfen. Geschlossene, fehlerfreie STL-Modelle liefern die besten Ergebnisse.

So probierst du es aus

  1. Beispiel-Kugel laden.
  2. „Negativform berechnen“ anklicken.
  3. Beide 3D-Modelle ansehen und die Negativ-STL herunterladen.
