How-to · Modell-Chat

Vom ersten STL-Begriff zur eigenen 3D-Seite

So haben wir die Idee Schritt für Schritt geklärt und daraus eine Browser-Anwendung für eine STL-Negativform gemacht.

Der Startpunkt

Los ging es mit der Frage „STL – was ist das?“ Daraus wurde eine konkrete Aufgabe: Eine STL-Datei soll eingelesen und daraus eine Negativform erzeugt werden.

„STL einlesen ⇒ Ausgabe ⇒ Negativ davon“

Gemeint war eine Gegenform: Das geladene 3D-Modell wird als Hohlraum aus einem Block herausgerechnet.

So sind wir im Modell-Chat vorgegangen

1

Begriff und Ziel klären

Erst wurde geklärt, was eine STL-Datei enthält. Dann wurde das Ziel festgelegt: STL laden und eine Negativform als neue STL-Datei ausgeben.

2

Die passende Umsetzung wählen

Auf die Frage, ob das ohne Python geht, fiel die Wahl auf eine HTML-Seite mit JavaScript. Die Berechnung soll lokal im Browser laufen; eine Installation ist nicht nötig.

3

Die Ansicht konkretisieren

Die geladene STL sollte sichtbar sein. Danach wurde ergänzt: nicht nur eine 2D-Ansicht, sondern das Eingabemodell und das berechnete Ergebnis jeweils in 3D. Farben machen die Höhen- beziehungsweise Rasterebenen erkennbar.

4

Beispiele und Bedienung ergänzen

Zum Ausprobieren kamen drei Modelle hinzu: Kugel, Pyramide und Stufenblock. Eine 2D-Querschnittsansicht blieb als zusätzliche Kontrolle erhalten.

5

Als eigene Unterseite ablegen

Die Anwendung liegt getrennt von der Startseite im Ordner Fabdie. Es gibt absichtlich keinen Link von der Homepage dorthin.

Was die Seite kann

  1. Eine eigene ASCII- oder Binär-STL-Datei laden oder eines der drei Beispiele wählen.
  2. Rasterabstand, Blockrand und Modellüberstand einstellen.
  3. Eingabe und erzeugte Negativform nebeneinander in 3D ansehen, drehen und zoomen.
  4. Das Ergebnis als STL herunterladen; der Querschnitt durch die Mitte hilft bei der Sichtkontrolle.

Technik und Grenzen

Die Seite besteht aus HTML und JavaScript. Sie benötigt kein Python und lädt die ausgewählte Datei nicht auf einen Server hoch. Die Höhenfarben visualisieren die Rasterebenen.

Wichtig: Die Negativform wird in dieser Demo als Voxel- beziehungsweise Raster-Näherung erzeugt. Dadurch können sichtbare Stufen entstehen; es ist keine exakte CAD-Boolesche Operation. Vor einem 3D-Druck die ausgegebene STL im Slicer prüfen. Geschlossene, fehlerfreie Modelle liefern die besten Ergebnisse.

Die Idee dahinter

Die Anwendung entstand nicht aus einem fertigen Pflichtenheft. Wir haben erst die Aufgabe beschrieben und anschließend anhand der Vorschauen entschieden, was noch fehlt: sichtbares 3D-Modell, 3D-Ergebnis, Ebenenfarben, drei Testmodelle und eine eigene Unterseite. So wurde aus einer kurzen Frage ein kleines, direkt ausprobierbares Projekt.
